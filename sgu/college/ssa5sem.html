Создать таблицу mysql:

  1. Запустить терминал, ввести команду: mysql -u root -p
  2. В поле пароля ввести: root
  3. После этого воспользоваться командой create database для создания базы данных <имя_вашей_БД>
  4. Переключиться на созданную БД командой use <имя_вашей_БД>
  5. Создать при помощи create table таблицу согласно выбранной предметной области
  6. Вставить 10 строк в новую таблицу.
  7. Осуществить выборку всех строк при помощи оператора select.
