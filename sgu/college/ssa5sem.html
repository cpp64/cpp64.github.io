Скачать установщик MySQL для Windows

Раздел 1

Создать таблицу mysql:

  1. Запустить терминал, ввести команду: mysql -u root -p
  2. В поле пароля ввести: root
  3. После этого воспользоваться командой create database для создания базы данных <имя_вашей_БД>
  4. Переключиться на созданную БД командой use <имя_вашей_БД>
  5. Создать при помощи create table таблицу согласно выбранной предметной области: не менее 2 числовых столбцов, не менее 1 текстового и не менее 1 столбца дат.
  6. Вставить 10 строк в новую таблицу.
  7. Осуществить выборку всех строк при помощи оператора select.

    8. Примечание: для того, чтобы ввести предыдущую команду нажмите кнопку "↑".

Раздел 2

  1. Сделать таблицу из 1 раздела первичной, для этого сделать первичный ключ на ней
  2. Создать 2 таблицу (вторичную), на которой будет задан внешний ключ
  3. Вставить не менее 10 строк во вторичную таблицу
  4. Осуществить join-выборку из 1 и 2 таблиц с пересечением по общей паре первичный-внешний ключ
